# Включайся! — панель для After Effects (папка расширения: AutoPogodaPanel)

## Что это
CEP-панель (расширение AE) с двумя кнопками:
1. **Обновить погоду** — сама дёргает pogoda.by по 6 городам и пишет
   температуру + нужную иконку в композиции `Card_Weather_01..06`.
2. **Загрузить новости в проект** — читаешь .docx с 10 новостями
   (один абзац = одна новость), панель сама пишет их в
   `Card_News_01..10`.

## Шаг 1 — два файла, которые нужно скачать самому
Я не могу их сюда вставить (это готовые библиотеки размером в сотни КБ
с других сайтов, качать их с моей стороны технически нельзя).
Положи оба файла в `client/js/`:

1. **CSInterface.js** — официальная библиотека Adobe для связи панели
   с приложением. Официальный источник — репозиторий Adobe CEP на
   GitHub, папка `CEP-Resources/CEP_11.x/CEPEngine_extern/CSInterface.js`
   (ищи "Adobe CEP-Resources CSInterface.js" в поиске — файл
   свободный, без ограничений использования).
2. **jszip.min.js** — библиотека для чтения .docx (это ZIP-архив
   внутри). Официальный сайт `stuk.github.io/jszip` → Download →
   `jszip.min.js`.

## Шаг 2 — куда положить папку расширения

**Windows:**
```
C:\Users\<твоё_имя>\AppData\Roaming\Adobe\CEP\extensions\AutoPogodaPanel
```
Скопируй туда всю папку `AutoPogodaPanel` (с manifest.xml, client/, host/) целиком.

## Шаг 3 — разрешить непроверенные (unsigned) расширения

Adobe по умолчанию блокирует расширения без цифровой подписи.
Включаем debug-режим один раз:

1. Win+R → `regedit`
2. Перейти в `HKEY_CURRENT_USER\Software\Adobe\CSXS.11`
   (число `.11` может отличаться в зависимости от версии AE —
   если ветки CSXS.11 нет, проверь CSXS.9/.10/.12 — версия должна
   совпадать с `RequiredRuntime` в manifest.xml, там указано 9.0,
   но подойдёт и более новая ветка реестра)
3. Создать строковый параметр `PlayerDebugMode` со значением `1`
4. Перезапустить After Effects

## Шаг 4 — открыть панель
В AE: `Window → Extensions → Включайся!`

## Шаг 5 — собрать сам шаблон-проект (один раз)
По схеме, которую мы обсуждали:
- Композиции `Card_Weather_01`..`06` внутри `LANE_WEATHER`
- Композиции `Card_News_01`..`10` внутри `LANE_NEWS`
- Обе dorozhki внутри `MASTER` (200 сек, 50 fps)
- В каждой `Card_Weather_XX`: текстовые слои `txt_city`, `txt_temp`,
  и ровно 8 слоёв-иконок с именами `icon_clear`, `icon_cloudy`,
  `icon_overcast`, `icon_rain`, `icon_storm`, `icon_snow`, `icon_fog`,
  `icon_wind` — все друг на друге, видимость переключает панель.
- В каждой `Card_News_XX`: текстовый слой `txt_news` + подложка
  `bg_auto` с expression на `sourceRectAtTime()`.

**Важно:** имена слоёв и композиций должны совпадать буква в букву —
именно по ним ExtendScript находит, куда писать данные.

## Проверка связи
Открой Console панели (правый клик на панели → Inspect, если
включён debug) и в консоли ExtendScript-стороны можно вызвать
`ping()` — вернёт подтверждение, что host.jsx загрузился и видит
текущий открытый проект.

## Если что-то не находится
Самая частая причина ошибки "comp not found" или "layer not found" —
опечатка в имени слоя/композиции в AE-проекте. Имена регистрозависимы
и должны быть ровно такими, как в этом README.
